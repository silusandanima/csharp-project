# CraftConnectPOS

CraftConnectPOS is a desktop Point of Sale and business management application designed for small artisan and craft businesses. The system helps users manage daily business activities such as products, materials, suppliers, customer orders, sales statistics, and dashboard summaries in one place.

The application includes user authentication, product management, material inventory management, supplier management, order management, dashboard overview, and sales statistics.

---

## Main Purpose of the Application

The purpose of CraftConnectPOS is to support artisan businesses by providing a simple system to:

- Register and log in users
- Manage product details
- Track raw materials and stock levels
- Manage supplier information
- Create and manage customer orders
- View dashboard summaries
- Analyze sales and revenue statistics

This allows the business owner or staff member to organize important business data more efficiently.

---

## Application Sections

The application contains the following main sections:

### 1. Login

The Login page allows an existing user to enter their username and password to access the system.

After successful login, the user is redirected to the main dashboard of the application.

---

### 2. Sign Up

The Sign Up page allows a new user to create an account.

The user enters their account details and creates login credentials. After registration, the user can log in and use the system.

---

### 3. Dashboard

The Dashboard gives an overview of the business.

It displays important summary information such as:

- Total products
- Total orders
- Revenue summary
- Low-stock materials
- Recent order information

This page helps the user quickly understand the current status of the business.

---

### 4. Products

The Products section is used to manage items sold by the business.

Users can:

- Add new products
- View existing products
- Edit product details
- Search products
- Delete products when allowed

Product details may include product name, description, price, and stock quantity.

---

### 5. Materials / Inventory

The Materials or Inventory section is used to manage raw materials used for creating products.

Users can:

- Add materials
- Update material quantity
- Assign suppliers to materials
- Set reorder levels
- View stock status

The system helps identify whether a material is in stock, low in stock, or out of stock.

---

### 6. Suppliers

The Suppliers section manages supplier information.

Users can:

- Add supplier details
- View supplier records
- Edit supplier information
- Search suppliers
- Delete supplier records when appropriate

Supplier information may include supplier name, phone number, and address/location.

---

### 7. Orders

The Orders section is used to manage customer purchases.

Users can:

- Create customer orders
- Select products for an order
- Enter order quantity
- View calculated totals
- Update order status
- Delete or manage existing orders

This section helps keep track of customer purchases and order history.

---

### 8. Statistics

The Statistics section provides sales and business analysis.

It may display:

- Total revenue
- Completed orders
- Monthly revenue
- Top-selling products
- Product revenue breakdowns

This section helps users understand business performance using saved order data.

---

## How to Run the Application

The application build is available inside the `Release` folder.

### Steps to run:

1. Open the project folder.
2. Go to the `Release` folder.
3. Find the application executable file.
4. Double-click the `.exe` file to launch the application.

Example:

```text
Release/CraftConnectPOS.exe
```
