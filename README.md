# CraftConnectPOS

WPF point-of-sale and inventory frontend targeting .NET Framework 4.8.

## Build

```powershell
dotnet build .\CraftConnectPOS\CraftConnectPOS.csproj -c Debug
```

The x64 executable is written under
`CraftConnectPOS\bin\Debug\net48\win-x64`.

## Demo data

Inventory, suppliers, products, and orders use lightweight in-memory sample
data. Demonstration changes reset when the application restarts.
